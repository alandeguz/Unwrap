# Unwrap

Welcome to **Unwrap**, a self-documenting alternatives to using a force unwrap operator.

See [the discussion on the Swift forums](https://forums.swift.org/t/moving-toward-deprecating-force-unwrap-from-swift/43455) for the rational as to why one might use this package.
